# 山河足迹 · 中国旅行地图

手机与桌面均可使用的旅行地图，支持城市插旗、城市着色、首次到访日期、旅行笔记和 CSV 导出。本轮增加先以游客身份记录、需要云端保存时再注册或登录的流程；网页托管在 GitHub Pages，邮箱账号与个人云端存档由 Supabase 提供。

**本轮游客流程与注册双密码确认已通过本地验收，正在准备发布。** 独立复跑的 69 项测试全部通过，实际浏览器已确认游客保存后刷新恢复，手机注册表单的确认密码必填且按钮完整可见。现有 [线上云端版](https://tanghongliang1024-boop.github.io/shanhe-atlas/) 已通过真实邮箱注册、验证、登录、云端保存及同浏览器新标签页恢复验收；真正的跨设备同步、密码找回和多账号完整流程仍未实测。具体完成项与待办见 [部署状态](supabase/DEPLOYMENT-STATUS.md)。

## 先在本机记录

无需注册或登录即可标记、编辑和删除城市，填写首次到访日期与笔记，并导出 CSV。游客足迹临时保存在当前网站、当前浏览器的本地存储中，正常刷新页面可以恢复。

“本机临时保存”不代表云端备份。清理浏览器数据、使用其他浏览器或换设备后，这些草稿无法自动取回；希望长期留存时，请主动保存到云端或导出 CSV。

## 需要云端保存时再注册或登录

点击“保存到云端”后默认进入注册，也可以切换登录已有账号。注册需要输入两次密码，两次一致后才提交注册请求；完成邮箱验证并登录后，才可保存到个人云端存档。

游客草稿上传以用户明确发起的保存请求为准，并绑定这次请求使用的邮箱。完成同一邮箱的验证或登录后，先读取该账号的云端存档，再合并待保存草稿：云端已经存在的同城记录优先，只补充云端没有的城市。普通账号登录本身不代表授权上传本机草稿。

云端保存会等待服务器确认，页面显示“已保存到云端”才表示成功。失败时保留草稿供重试；成功后，仅清理保存期间未被继续修改的草稿，避免丢失新增编辑。两个页面从同一版本编辑云端存档时，版本检查（CAS）只允许其中一次保存成功，另一处提示刷新后重新编辑。

成功保存的云端足迹可由同一账号再次读取。各账号的云端档案彼此隔离，游客草稿保存在独立的本机存储中，不自动写入其他账号。

每份存档按登录用户隔离。前端只包含公开的项目 URL 和 publishable key；数据库密码、服务端密钥和 SMTP 密码不属于网页配置。

## 旧版本机记录与导出

旧版 `shanhe-atlas-v1` 足迹与本轮游客草稿分开保留。登录后，在“我的存档”点击“导入本机足迹”，才会将旧记录保存到当前账号；只补充云端没有的城市，同城以云端记录为准，原本机备份保留。它不会因为浏览地图、注册或登录而被自动上传。

导入只能读取当前网站域名下、当前浏览器保存的旧记录。原 Sites 地址的本机数据不会自动转移到 GitHub Pages，也不会因登录而自动上传。CSV 导出用于另存备份；当前没有 CSV 导入功能。成功保存到云端的足迹在清理本机浏览器数据后仍可重新登录读取，但未导入的本机旧记录可能丢失。

## 发布到 GitHub Pages

1. 先按 [Supabase 部署说明](supabase/README.md) 完成数据库、邮箱验证、自定义 SMTP 和 Auth 返回地址配置，并核对 [部署状态](supabase/DEPLOYMENT-STATUS.md) 中的配置检查项。
2. 检查 `cloud-config.js` 只包含目标项目的公开 URL 与 publishable key。当前项目为 `gxaeatehlgepgeuhhmll`；不要把密码或私密密钥写入这个文件。
3. 将发行包中的文件放到 GitHub 仓库根目录，确保根目录直接包含 `index.html`、`.nojekyll`、`guest-store.js` 和 `assets/`。本轮允许清单为原 23 文件加 `guest-store.js`；开发用测试、预览服务和模拟登录工具不属于发行包。
4. 在 Settings → Pages → Build and deployment 中选择 Deploy from a branch，选择 `main` 分支与 `/(root)` 文件夹并保存。
5. 等待 Pages 工作流成功，再在公开网址验证注册、邮箱回跳、登录、保存和跨设备读取。

目标网址：<https://tanghongliang1024-boop.github.io/shanhe-atlas/>。静态网页无需 Node.js 运行服务或自购云主机，所有资源路径兼容仓库子路径；账号和存档功能需要可用的 Supabase 项目及邮件服务。

## 数据和许可

边界与坐标来自阿里云 DataV：https://datav.aliyun.com/portal/school/atlas/area_selector 。当前包含 391 个可标记地区；直辖市和港澳按整体记录，台湾细分为 22 个县市（含澎湖、金门、连江），详见网页中的数据说明。

台湾县市边界采用 2025-03-18 官方数据的网页简化版本，来源及授权见 [台湾县市数据说明](assets/TAIWAN-DATA-SOURCES.md)。支持简繁体名称搜索，点击地图下方“台湾县市”可快速放大。

旧版台湾整体足迹会显示待整理提示；用户选择对应县市后，原日期和记忆完整保留，已有县市记录不会被覆盖。未整理的旧记录仍可导出。
